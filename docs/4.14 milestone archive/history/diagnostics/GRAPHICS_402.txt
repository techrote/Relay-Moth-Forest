QUALITY LADDER
--------------
0  static/disabled deformation; gameplay unaffected
1  coarse 3-band-style weighting, primary wind, small interaction budget
2  four-band-style weighting, primary+secondary wind, bend pseudo-normal, interaction push
3  smooth 4–5-band-equivalent response, gusts, upper flutter, combined bump+bend response, <=8 sources

ROOTING
-------
Every physical foliage sprite has a category/region root cutoff. Shader deformation is exactly
zero at/below that cutoff. Typical cutoff is 30–45% from the bottom. Tip motion receives the
full wind/interaction response; roots remain attached to the same logical ground coordinate.

WIND
----
Primary world-space wavelength:   216 logical px
Secondary world-space wavelength:  94 logical px
Nearby foliage therefore samples related motion. Small deterministic variation is intentionally
subordinate to the coherent field.

CONTACT AO / SHADOWS
--------------------
Each instance supplies a stable root footprint. Contact AO is drawn into the same half-resolution
MAX shadow mask used by ordinary casters, so overlapping shadow contributions do not repeatedly
multiply darkness. Water-mask rejection is retained for foliage contact AO.

FLOATER-FX
----------
Floater-FX remains the pink/purple magical/experimental effect family. It is OFF by default,
independent of the SurfaceFX master toggle, and reads only explicit `floater_clumps` authoring.
The shipping v4 maps contain no Floater clumps, so physical grass placement is never borrowed.
