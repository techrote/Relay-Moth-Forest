# 4.14 milestone archive

This directory is the historical documentation snapshot that existed when the v4.14 milestone was consolidated.

It contains the former:

- \`docs/current/\`;
- \`docs/history/\`;
- \`docs/validation/\`;
- root \`README.txt\`.

The files are retained for provenance, release archaeology and comparison with the executable evidence that shipped with the milestone.

They are **not the current documentation contract**. Current subsystem documentation now lives directly under \`docs/\`.

The packaged v4.14 milestone artefacts remain under:

\`\`\`text
milestones/v4.14/
\`\`\`

Those artefacts include the release ZIP, checksum, Tin Stream capture, sprite-render audit and validation log.

When historical documents disagree with the current runtime or current docs, prefer:

1. current runtime/data;
2. executable tests;
3. current docs;
4. changelog;
5. this archive.
